# Snake AI

这是为 2014 年为中国海洋大学华为俱乐部举办的比赛准备的 AI 编程题目。参赛选手们展现了出色的编程能力，最终的最高分比我预期的要高得多。

选手们最终提交的参赛代码公开于 https://github.com/simonmysun/Snake-AI/tree/gh-pages/judge 。

题目在比赛后依然开放，欢迎大家小试牛刀，看看能不能击败当年的选手们。项目源码：https://github.com/simonmysun/Snake-AI/

## 使用方式

请阅读[游戏介绍](https://maoyin.eu/Snake-AI/intro/)和[游戏规则](https://maoyin.eu/Snake-AI/intro/rules/)后依据[API 说明](https://maoyin.eu/Snake-AI/api/)编写代码在[沙盒](https://maoyin.eu/Snake-AI/game/)中运行并查看分数。
